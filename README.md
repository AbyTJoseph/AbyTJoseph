## 🚀 Project Spotlight

### [TestAbyLity.com](https://testabylity.com/) - GenAI for Software Testing

**Personal engineering project • Built in 2024 • MVP / technical showcase**

In **2024**, I built **TestAbyLity**, an experimental GenAI-powered testing platform, to explore a simple question: *Can LLMs reduce repetitive work in software testing?*

The prototype explored five workflows:

- **API test generation** from OpenAPI/Swagger specifications to REST Assured tests.
- **Page Object creation** from HTML DOM to Selenium classes.
- **Test migration** from Java Selenium to TypeScript Playwright.
- **Requirements analysis** for ambiguity and testability gaps.
- **AI testing assistance** using retrieval-augmented generation.

**Built with:** React, Java, Spring Boot, Spring AI, Anthropic Claude, OpenAI, Hugging Face embeddings, Chroma DB, and Firebase.

The website is a retrospective of the MVP, its architecture, experiments, trade-offs, and lessons learned - **not a production SaaS offering**.
